# 🌾 Farm Life — Unity Farming Simulation

A farming simulation game built with Unity and C# — the first complete game title from Mischief Gaming Studios. Plant crops, manage resources, and build your farm from the ground up.

---

## 🎮 About the Game

Farm Life is a top-down farming simulation where players manage their own farm. It was built as a first complete game project to learn Unity's core systems including scene management, game loops, player input, and object interaction.

**Core gameplay includes:**
- Planting and harvesting crops
- Resource and inventory management
- Farm progression and upgrades
- Day/night or seasonal cycle

---

## 🛠️ Tech Stack

- **Engine:** Unity
- **Language:** C#
- **Platform:** PC

## 🚀 Getting Started

### Prerequisites

- [Unity Hub](https://unity.com/download) installed
- Unity Editor (check the project's `ProjectSettings/ProjectVersion.txt` for the exact version)

### Running the Project

1. Clone the repository:
```bash
git clone https://github.com/TroyWenzel/Farm-Life-Unity-and-C-first-project.git
```

2. Open **Unity Hub**

3. Click **"Add project from disk"** and navigate to the cloned folder

4. Open the project in the Unity Editor

5. In the **Project** panel, navigate to `Assets/Scenes` and open the main scene

6. Press the **Play** button to run the game in the editor
